## Epigusto

#### Description

**Epigusto** est un jeu de plateforme en 2D au style rétro développé en seulement 48 heures lors d'un hackathon Epitech. Le joueur incarne un personnage en course infinie, devant éviter des obstacles, collecter des objets et survivre le plus longtemps possible. Plus le temps passe, plus le rythme s’accélère, rendant le défi toujours plus intense.

#### Conception

Le projet a été conçu pendant un hackathon de 48 heures avec une équipe de trois développeurs. Les contraintes imposées ont fortement orienté les choix de conception : nous avons opté pour un gameplay simple mais efficace (runner automatique), un design pixel art accessible et une base de code intégralement rédigée en italien pour ajouter une touche originale au projet. Le développement s’est concentré sur la réactivité des contrôles, la fluidité du jeu et l’équilibrage des éléments aléatoires.

#### Fonctionnalités

L'application contient les fonctionnalités suivantes :

- **Course infinie** : Le personnage court automatiquement et le joueur doit uniquement gérer les sauts pour éviter les pièges.
- **Système de score** : Les pièces collectées augmentent le score, incitant à prendre des risques calculés.
- **Bonus variés** : Cœurs, caisses, lapins, tortues et le très rare Phénix influencent temporairement le gameplay.
- **Difficulté évolutive** : Le jeu devient plus rapide et complexe au fil du temps.
- **Effets sonores originaux** : Tous les sons du jeu ont été créés sur mesure par l’équipe.
- **Code source en italien** : Une contrainte originale respectée dans tout le code source.
- **Easter egg** : Un secret caché attend les joueurs les plus curieux.
- **Tableau des scores** : Permet aux joueurs de comparer leurs performances.
